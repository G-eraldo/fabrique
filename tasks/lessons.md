# Leçons durables

- Avant d'écarter un projet du portfolio, recouper les captures du dépôt et les informations du propriétaire ; une URL momentanément inaccessible ne suffit pas.
- Vérifier le rendu des images `next/image` dans le navigateur après modification ; si le propriétaire choisit Cloudinary, configurer son domaine et tester les captures hébergées.
- Dans un formulaire à étapes, tester l'envoi réel depuis la dernière étape : les champs requis masqués peuvent bloquer la validation native sans être focalisables.
- Pour une connexion PostgreSQL TLS, tester une requête réelle et journaliser uniquement l'étape et le code d'erreur ; une compilation réussie ne valide ni le certificat ni l'accès réseau.
- Quand deux CTA voisins promettent des intentions différentes, leur donner des parcours distincts ; un simple préremplissage du même formulaire ne suffit pas.
