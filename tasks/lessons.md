# Leçons durables

- Avant d'écarter un projet du portfolio, recouper les captures du dépôt et les informations du propriétaire ; une URL momentanément inaccessible ne suffit pas.
- Vérifier le rendu des images `next/image` dans le navigateur après modification ; si le propriétaire choisit Cloudinary, configurer son domaine et tester les captures hébergées.
